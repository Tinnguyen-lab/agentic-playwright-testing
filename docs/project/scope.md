# Project Scope

## 1. Trong phạm vi

- Kiểm thử ứng dụng web.
- Functional end-to-end testing.
- Playwright bằng Python.
- Tài liệu DOCX, PDF dạng văn bản, Markdown và plain text.
- Use case, user story kèm acceptance criteria và functional requirement.
- Chuẩn hóa yêu cầu.
- Phát hiện yêu cầu thiếu, mơ hồ hoặc mâu thuẫn.
- Sinh positive, negative, boundary và alternative-flow test case.
- Requirements traceability.
- DOM hoặc accessibility grounding.
- Thực thi test và thu thập log, trace, screenshot.
- Repair proposal có ràng buộc.
- Human-in-the-loop approval.
- Thực nghiệm trên khoảng ba ứng dụng web.

## 2. Ngoài phạm vi

- Mobile application testing.
- Desktop application testing.
- Performance testing.
- Security testing.
- Accessibility testing toàn diện.
- Sinh Selenium, Cypress và Playwright cùng lúc.
- Tự sửa source code của ứng dụng được kiểm thử.
- Tự động xác định hoàn toàn test oracle từ yêu cầu mơ hồ.
- Huấn luyện hoặc fine-tune LLM từ đầu.
- Hệ thống hoàn toàn tự vận hành không cần con người.
